# :books: Liane's Library 
This repository provides a sample of all the files to set up a working library management system for Liane and her private book loans. The project utilizes a local MySQL database to manage loans and a Streamlit frontend for no-code use. This is a proof of concept for educational purposes, and does not attempt to package the final product for non-technical users.

## :floppy_disk: Dataset
While the real user would need to enter data, testing data is generated by running `sql_scripts/populate_schema.sql`. Entries are AI-generated; all people and loans are fictional, but some book titles represent real books.

## :open_file_folder: Project Structure
* `notebooks/`: development space for library management functionalities; distinct from any Streamlit logic
* `sql_scripts/`: for setting up the library database and providing sample data for development and testing
* `src/`: files for running the Streamlit application; divided into two categories
    *  streamlit files
        * `app.py`: define app layout and interaction widgets
        * `login.py`: provide login functionality
    * 'pure python' files for library management; these are portable and can be used in a different frontend if desired
        * `create.py`: functions to add borrowers and books, and to issue new loans
        * `db.py`: helper file to separate identification of sqlalchemy engine from frontend login
        * `delete.py`: functions to remove borrowers and books, and to return loaned books
        * `read.py`: functions for reading sql data and formatting table reads for user-friendly view
        * `update.py`: functions for modifying borrower, book, and loan data
        * `validate.py`: functions to check conformity of user-entered values against expectation
* `con_EXAMPLE.py`: shows the structure of a sqlalchemy connection string; use as a template to create `con_lib.py` to ease login when developing
* `environment.yml`: necessary python libraries; formatted to build a conda virtual environment

## :gear: How to use this project
Prerequisites for this project are a local MySQL server and an IDE of choice. Other necessary installs can be found in `environment.yml`, which is formatted to install a conda virtual environment named `lianes-lib-env`. Once all tools are in place, run `sql_scripts/define_schema.sql`. 

To launch the application, open a terminal in `src/`, activate the `lianes-lib-env` environment, and run `streamlit run app.py`. 

Working with `notebooks/CRUD.ipynb` to develop or modify library management functions, open `con_EXAMPLE.py`, enter the password for the local MySQL server on line 4, and save as `con_lib.py`.
